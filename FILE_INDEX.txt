LAUNCH SCRIPTS EXPLAINED:
=========================

./launch-server.ps1
   Purpose: Start the server
   Prerequisites: Node.js, yarn installed
   Time: 5-10 seconds to start
   Output: "Express server listening on port 8082"
   Next step: Run launch-game-2p.ps1 in another terminal

./launch-server.bat
   Purpose: Alternative to launch-server.ps1 (Command Prompt)
   Prerequisites: Node.js, yarn installed
   Time: 5-10 seconds to start
   Output: "Express server listening on port 8082"
   When to use: If PowerShell doesn't work

./launch-game-2p.ps1
   Purpose: Launch two-player local battle
   Prerequisites: Server running (launch-server.ps1), game installed
   Time: 3-5 seconds to launch
   Result: Two game windows side-by-side, auto battle
   Parameters: None required (defaults to test & Pieloaf)

./launch-game-1p.ps1
   Purpose: Launch single-player queue testing
   Prerequisites: Server running, game installed
   Time: 3-5 seconds to launch
   Result: One game window, waits in queue for opponent
   Parameters: -Username, -SteamId, -ServerUrl (optional)

IF SOMETHING GOES WRONG:
=======================

1. Check Terminal 1 (Server)
   - Should see: "Express server listening on port 8082"
   - If error, try: yarn build && yarn dev

2. Check Terminal 2 (Game)
   - Should see: Game windows launching
   - If error, check SCRIPTS_README.md troubleshooting

3. Check file permissions
   - Scripts should be executable
   - If Windows blocks scripts: Set-ExecutionPolicy RemoteSigned

4. Check dependencies
   - Node.js: node --version (should be v18+)
   - yarn: yarn --version (should exist)
   - Game: File Explorer → Program Files (x86) → Steam → ...

5. See comprehensive troubleshooting
   - SCRIPTS_README.md (6 scenarios)
   - LAUNCH_GUIDE.md (11 scenarios)
